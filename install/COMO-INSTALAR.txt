===============================================================================
  DetalhaBIM para Revit 2027 — COMO INSTALAR (sem instalador e sem scripts)
===============================================================================

A instalação é só copiar 2 arquivos. Nada precisa ser executado.

-------------------------------------------------------------------------------
  PASSO 0 — DESLIGUE O "CONTROLE DE APLICATIVO INTELIGENTE" (obrigatório)
-------------------------------------------------------------------------------
O DetalhaBIM ainda não tem assinatura digital. Com esse recurso do Windows 11
ligado, o Windows impede o Revit de carregar o plugin, e não existe opção
"Permitir" para esse bloqueio.

  - Clique em Iniciar e digite:  Controle de Aplicativo Inteligente
    (ou: Segurança do Windows > Controle de aplicativos e do navegador >
     Configurações do Controle de Aplicativo Inteligente)
  - Selecione "Desativado" e confirme. NÃO use "Avaliação".
  - Reinicie o computador.

O Microsoft Defender Antivírus continua protegendo o computador. Com a
atualização de abril de 2026 do Windows 11 (KB5083769 ou mais recente), o
recurso pode ser religado depois pela mesma tela (o plugin então para de
carregar).

-------------------------------------------------------------------------------
  PASSO A PASSO
-------------------------------------------------------------------------------
1) Feche o Revit.

2) Se você tentou instalar antes, apague o que sobrou, se existir:
        %AppData%\Autodesk\ApplicationPlugins\DetalhaBIM.bundle   (pasta)
        %AppData%\Autodesk\Revit\Addins\2027\DetalhaBIM          (pasta)
        %AppData%\Autodesk\Revit\Addins\2027\DetalhaBIM.addin    (arquivo antigo)

3) Extraia este .zip (botão direito > "Extrair tudo...").

4) Abra a pasta  "COPIAR PARA Addins 2027". Dentro dela há 2 arquivos:
        DetalhaBIM.addin
        DetalhaBIM.dll
   Selecione os dois (Ctrl+A) e copie (Ctrl+C).

5) Clique na barra de endereço do Explorador de Arquivos, cole o texto abaixo
   e tecle Enter:

        %AppData%\Autodesk\Revit\Addins\2027

   Se a pasta 2027 não existir, crie-a dentro de ...\Autodesk\Revit\Addins.
   Cole ali os 2 arquivos (Ctrl+V). Os dois precisam ficar LADO A LADO, na
   mesma pasta:

        ...\Autodesk\Revit\Addins\2027\DetalhaBIM.addin
        ...\Autodesk\Revit\Addins\2027\DetalhaBIM.dll

   Se o Revit disser que o arquivo .dll "não existe", a DLL não está ao lado
   do .addin, ou foi removida pelo antivírus (confira em Segurança do Windows >
   Histórico de proteção).

6) Abra o Revit 2027. Se aparecer o aviso de complemento não assinado,
   escolha "Sempre carregar". A aba "DetalhaBIM" aparece na faixa de opções.

   Por que essa pasta? No Revit 2027, a pasta de complementos do usuário é o
   único local que o Revit garante carregar para plugins sem assinatura digital.


-------------------------------------------------------------------------------
  SE A ABA AINDA NÃO APARECER
-------------------------------------------------------------------------------
A) Com o Revit aberto, veja se esta pasta existe:
        %AppData%\DetalhaBIM\logs
   Se existir, o plugin carregou. Envie as últimas linhas do arquivo .log.

B) Iniciar > Segurança do Windows > Histórico de proteção.
   Se aparecer um bloqueio NOVO (com data e hora de agora) citando
   DetalhaBIM.dll, o Controle de Aplicativo Inteligente continua ligado.
   Refaça o Passo 0.

C) Diário (journal) do Revit — mostra exatamente o que o Revit fez com o plugin:
   - Feche o Revit, abra-o novamente e feche de novo.
   - Cole na barra de endereço:
        %LocalAppData%\Autodesk\Revit\Autodesk Revit 2027\Journals
   - Ordene por "Data de modificação" e abra o journal.XXXX.txt mais recente
     no Bloco de Notas.
   - Tecle Ctrl+F, procure por  DetalhaBIM  e envie as linhas encontradas
     (ou uma foto delas).
   - Se não houver nenhuma linha com DetalhaBIM, o Revit não encontrou o
     arquivo DetalhaBIM.addin. Confira o caminho do passo 5.


-------------------------------------------------------------------------------
  ATUALIZAR E DESINSTALAR
-------------------------------------------------------------------------------
Atualizar:    com o Revit fechado, substitua os 2 arquivos pelos novos.
Desinstalar:  com o Revit fechado, apague DetalhaBIM.addin e DetalhaBIM.dll
              de %AppData%\Autodesk\Revit\Addins\2027.

As suas configurações ficam em %AppData%\DetalhaBIM e são mantidas.
